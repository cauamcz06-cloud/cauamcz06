## 👨‍💻 Sobre mim

Sou **Cauã Melo de Amorim**, um desenvolvedor com foco na construção de soluções no **Back End**. Atualmente, estudo Análise e Desenvolvimento de Sistemas (ADS) no Centro Universitário Mário Pontes Jucá (UMJ). 

Busco criar aplicações eficientes, escaláveis e de alta performance, mantendo um design de código limpo e minimalista.

- 🔭 Atualmente aprimorando minhas habilidades em arquitetura de software e design de APIs.
- 📚 Focado no desenvolvimento de sistemas utilizando **Python** e **Golang**.
- 🎯 Objetivo: Tornar-me um especialista na criação de microsserviços e sistemas robustos no Back End.
